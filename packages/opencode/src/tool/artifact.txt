Show something you made — a page, a brief, a table, a snippet — in the Artifacts pane beside this conversation, where the user and every other agent in this session can see it.

Use it for output the user will want to LOOK AT rather than read in the transcript: an HTML page, a markdown document, a CSV table. Do not paste the same content into your reply as well; say what you made and let the pane show it.

Actions:
- create: title, kind (html | markdown | csv | code), content, optional language (for code). Returns the artifact id and revision 1.
- update: id, full new content (and title/kind if they change). Pass base_revision = the revision you last read; if someone else wrote since, the update is refused and tells you who — read it again and apply your change to the current version instead of overwriting theirs.
- read: id. Returns the current content, its revision, and who wrote it.
- list: every artifact in this session, newest first, with its revision and author.

The pane is shared by every agent in the session, subagents included. Other agents' artifacts appear in list; check it before creating something that may already exist. HTML runs in a sandbox: scripts work, but it cannot reach the app, the network as the user, or localStorage.
